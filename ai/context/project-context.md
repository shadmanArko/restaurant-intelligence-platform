# Project Context

Project Name:
Restaurant Intelligence Platform

Purpose:

Restaurant Intelligence Platform (RIP) is an AI-augmented restaurant operations platform designed for cloud kitchens, restaurants, and future SaaS deployment.

Core Domains:

* Identity
* Customers
* Orders
* Menu
* Recipes
* Production
* Inventory
* Purchasing
* Accounting
* Analytics

Architecture:

* Modular Monolith
* Clean Architecture
* Event Driven Architecture
* DDD Lite

Backend:

* NestJS
* TypeScript
* Drizzle ORM
* PostgreSQL
* Redis

Frontend:

* Next.js
* TypeScript
* Tailwind
* shadcn/ui

Infrastructure:

* Docker
* Turborepo
* pnpm

Protected Domains:

* Accounting
* Inventory
* Production

Requirements:

* Auditability
* Event Sourcing Ready
* Multi-Branch Ready
* Cloud Kitchen Ready
* AI Ready

Important:

Business rules are more important than frameworks.

Domain models are more important than database design.

Maintainability is more important than implementation speed.
